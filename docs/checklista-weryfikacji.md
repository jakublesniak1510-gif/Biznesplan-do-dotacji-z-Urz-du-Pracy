# Checklista weryfikacji przed wysłaniem treści klientowi

Dla właściciela. Przejdź całą listę przy każdym zleceniu. Punkty oznaczone **⛔** blokują wysyłkę: popraw albo skontaktuj się z klientem. Czas: ok. 20–30 min na plan.

Wiedza o zasadach: `docs/jak-dziala-dotacja-2026.md`. Odpowiedzi klienta: kwestionariusz (`docs/kwestionariusz-klienta.md`).

---

## A. Kwalifikowalność klienta i naboru

- [ ] ⛔ Klient potwierdził wszystkie warunki z art. 148 (pyt. 1.6). Przy „nie jestem pewien” wyjaśniono to przed pracą.
- [ ] ⛔ Wniosek idzie do PUP właściwego dla **miejsca zamieszkania** klienta.
- [ ] ⛔ Mam **regulamin tego naboru** (nie regulamin ogólny ani zeszłoroczny). Data regulaminu i źródło finansowania (FP / EFS+ / PFRON) są zgodne z ogłoszeniem.
- [ ] Przy EFS+ klient należy do grupy docelowej projektu (wiek, długotrwałe bezrobocie itd.).
- [ ] ⛔ Zabezpieczenie jest realne (sekcja 2 kwestionariusza) według wymogów **tego** PUP: liczba poręczycieli, próg dochodu, wiek, forma zatrudnienia, brak ryczałtu, zgoda małżonka. Jeśli nie, klient dostał ostrzeżenie na piśmie.
- [ ] Jeśli PUP wymaga dotacji w IPD, klient o tym wie (pyt. 1.9).

## B. Zgodność z regulaminem

- [ ] ⛔ Rodzaj działalności i PKD **nie są na liście wykluczeń** (sezonowa, obwoźna, komis, lombard, rolnicza, przejęcie po rodzinie, spółka, wyłączenia de minimis itd.).
- [ ] ⛔ Kwota wnioskowana ≤ maksimum z ogłoszenia i ≤ 6× przeciętne wynagrodzenie (od 1.09.2026: 55 398,78 zł). Zaokrąglenie zgodne z wymogiem (np. „pełne setki” w Piotrkowie).
- [ ] ⛔ Każda pozycja kosztorysu jest w **katalogu dozwolonych wydatków**. Brak zakazanych: kaucje, leasing i raty, koncesje i opłaty, czynsz i media, ZUS, wynagrodzenia, nieruchomości, kasa fiskalna, ubezpieczenia, transport i przesyłka, szkolenia (jeśli wykluczone), zakupy od rodziny lub poręczyciela.
- [ ] ⛔ **Limity procentowe i kwotowe policzone od właściwej podstawy** (kwota wnioskowana czy przyznana – sprawdź w regulaminie):

| Pozycja | Limit z regulaminu | Wartość w kosztorysie | % kwoty | OK? |
|---|---|---|---|---|
| Reklama / materiały reklamowe / www | | | | |
| Towar handlowy, materiały | | | | |
| Remont / adaptacja | | | | |
| Samochód / środek transportu | | | | |
| Sprzęt używany (łącznie i za sztukę) | | | | |
| Doradztwo / pomoc prawna | | | | |
| Pozycje z limitem kwotowym (meble, IT, telefon, sklep internetowy) | | | | |

- [ ] Sprzęt używany spełnia warunki (minimalna wartość, sprzedawca, wycena, deklaracja pochodzenia) albo został zamieniony na nowy.
- [ ] Samochód: dozwolony typ (osobowy często wykluczony), limit %, zakup tylko na fakturę, jeśli regulamin tak wymaga.
- [ ] Sprzedaż internetowa: spełnione warunki regulaminu (np. własny sklep, a nie tylko aukcje).
- [ ] Wszystkie wymagane załączniki z regulaminu są na liście dla klienta (oferty, wizualizacje mebli, dokument lokalu, de minimis, oświadczenia poręczycieli).

## C. Spójność liczb

- [ ] ⛔ **Suma kosztorysu = kwota wnioskowana** we wszystkich miejscach wniosku (co do grosza).
- [ ] ⛔ Każda pozycja w specyfikacji wydatków ma uzasadnienie i **ofertę** (link lub screen) z ceną zgodną z kosztorysem (różnica 0 zł albo wyjaśniona).
- [ ] ⛔ Prognoza obejmuje **12 miesięcy osobno**, z uzasadnieniem założeń (liczba klientów × cena).
- [ ] Ceny usług w prognozie = cennik klienta (pyt. 3.2) i są w zakresie cen konkurencji (pyt. 8.1). Odchylenie ma uzasadnienie.
- [ ] Koszty stałe uwzględniają ZUS zgodny z wybranym wariantem, składkę zdrowotną zgodną z formą opodatkowania, czynsz, media, księgowość, paliwo, materiały. **Wydatki wykluczone z dotacji są w kosztach bieżących, a nie w kosztorysie.**
- [ ] Sezonowość z pyt. 3.5/13.2 jest widoczna w rozkładzie miesięcznym.
- [ ] Wynik jest realny: brak zysku od 1. miesiąca bez uzasadnienia, dochód pozwala utrzymać firmę 12 mies. Próg rentowności policzony.
- [ ] VAT: przy czynnym VAT jest informacja o zwrocie VAT do PUP (art. 152). Kwoty brutto i netto są spójne.
- [ ] Wkład własny w kalkulacji = deklaracja klienta (pyt. 10.1–10.3).
- [ ] Zatrudnienie z pyt. 12.1 jest w kosztach i w opisie.
- [ ] Liczby w tekście opisowym (np. „30 klientów miesięcznie”) = liczby w tabelach.

## D. Prawdziwość danych

- [ ] ⛔ Kwalifikacje i doświadczenie we wniosku wynikają z odpowiedzi klienta i (w miarę możliwości) z dokumentów. **Nic nie dopisano „dla punktów”.**
- [ ] ⛔ Nazwy konkurentów, adresy i ceny są prawdziwe. Sprawdzono co najmniej 2 z nich w Google Maps lub na stronie.
- [ ] ⛔ Listy intencyjne opisane we wniosku istnieją lub klient zobowiązał się je zdobyć. Treść nie przesadza (deklaracja to nie zamówienie).
- [ ] Opis lokalu zgadza się ze zdjęciami i odpowiedziami (możliwa wizja lokalna).
- [ ] Uprawnienia i zezwolenia: wniosek nie twierdzi, że klient je ma, jeśli ich nie ma. Jest plan uzyskania.
- [ ] Brak obietnic, których klient nie dotrzyma (np. „zatrudnię 2 osoby”, gdy nie planuje).

## E. Zgodność z formularzem urzędu

- [ ] ⛔ Treści przygotowano pod **aktualny formularz tego PUP** (wersja z naboru). Kolejność i numeracja pól są zgodne.
- [ ] ⛔ Limity znaków i miejsca w polach są dotrzymane (sprawdź w DOCX/PDF urzędu).
- [ ] Pola z danymi osobowymi (PESEL, adres, poręczyciele) zostawiono puste z dopiskiem „wypełnia wnioskodawca”.
- [ ] Wybrana forma zabezpieczenia wpisana tak jak w formularzu (nazwy z katalogu § 10 rozporządzenia).
- [ ] PKD w formacie podklasy (np. 96.02.Z – sprawdź aktualną klasyfikację PKD **[do weryfikacji: PKD 2025 a formularze PUP]**).
- [ ] Oświadczenia i załączniki de minimis wskazane klientowi jako „do wypełnienia i podpisania przez Ciebie”.
- [ ] Jeśli urząd wymaga „przygotowania wniosku pod względem formalnym” (np. wypełnienie komputerowe, podpisy na każdej stronie), dodano instrukcję dla klienta.

## F. Brak „generycznego AI”

- [ ] ⛔ W tekście są **konkrety**: nazwa miejscowości i ulicy, nazwy 3–5 konkurentów, konkretne ceny, liczby mieszkańców lub klientów ze źródłem, model sprzętu.
- [ ] ⛔ Brak fraz-wypełniaczy: „dynamicznie rozwijający się rynek”, „innowacyjne podejście”, „kompleksowa obsługa”, „wysoka jakość usług”, „indywidualne podejście do klienta”, „w dzisiejszych czasach”, „szeroki wachlarz”. Każde takie zdanie zastąp faktem albo usuń.
- [ ] Brak liczb „z powietrza” (np. „rynek wart 2 mld zł”) bez źródła. Dane statystyczne mają źródło (GUS, gmina) albo są usunięte.
- [ ] Tekst brzmi jak napisany przez wnioskodawcę: pierwsza osoba, słownictwo branżowe klienta, jego motywacja z pyt. 3.8. Bez korporacyjnego żargonu.
- [ ] SWOT i ryzyka są specyficzne dla tej firmy i tego miejsca, a nie uniwersalne.
- [ ] **Test bliźniaka:** porównaj z ostatnimi planami do **tego samego PUP** (lista w operacjach):
  - [ ] żadne zdanie dłuższe niż 8 słów nie powtarza się dosłownie,
  - [ ] inna struktura akapitów otwierających w opisie i analizie rynku,
  - [ ] inne przykłady, inne sformułowania ryzyk,
  - [ ] wspólne mogą być tylko fakty urzędowe (np. dane o powiecie). Je też sformułuj inaczej.
- [ ] Jeśli do jednego PUP idą 2+ plany w tym samym naborze: inny ton i układ. Zapisano to w rejestrze zleceń.

## G. Język i forma

- [ ] Pisownia i interpunkcja sprawdzone (korektor plus czytanie na głos najważniejszych sekcji).
- [ ] Polskie znaki poprawne (bez „?” i krzaków po kopiowaniu do DOCX urzędu).
- [ ] Liczby w polskim formacie: 12 500,00 zł. Jednolity zapis dat.
- [ ] Nazwy własne: urząd, ustawa „o rynku pracy i służbach zatrudnienia” (nie „o promocji zatrudnienia”), „dofinansowanie podjęcia działalności gospodarczej”.
- [ ] Brak wzmianek o AI, o naszej firmie, o „biznesplanie przygotowanym przez…”.

## H. Format wydruku i paczka dla klienta

- [ ] Plik DOCX (edytowalny) plus PDF podglądowy. Tabele nie wychodzą poza margines A4, nagłówki tabel powtarzają się na kolejnych stronach.
- [ ] Czcionka czytelna (11–12 pt), bez kolorów, które źle się drukują w czerni.
- [ ] Kosztorys i prognoza: arkusz plus wersja tabelaryczna wklejona do wniosku. Sumy w Wordzie zgodne z arkuszem.
- [ ] Instrukcja dla klienta (1 strona):
  - [ ] co wpisać samemu: PESEL, adresy, poręczyciele, oświadczenia, de minimis,
  - [ ] co podpisać,
  - [ ] które załączniki dołączyć (oferty, dokument lokalu, dyplomy, listy intencyjne),
  - [ ] termin i sposób złożenia (papier / e-Doręczenia / praca.gov.pl, rodzaj podpisu),
  - [ ] przypomnienie: **nie rejestrować firmy i nie kupować niczego przed umową**,
  - [ ] co robić przy wezwaniu do uzupełnień (termin ≥ 7 dni, nasz kontakt),
  - [ ] przy Premium: przygotowanie do rozmowy lub prezentacji, jeśli regulamin ją przewiduje.
- [ ] Nazwy plików: `PUP-[miasto]_[nazwisko-lub-ID]_wniosek_v1.docx`.

## I. Po wysłaniu

- [ ] Zlecenie wpisane do rejestru: PUP, nabór, branża, data, wersja. To podstawa testu bliźniaka.
- [ ] Ustawione przypomnienie o ankiecie po decyzji urzędu (ok. 30–45 dni od złożenia).
- [ ] Dane wrażliwe z uploadów usunięte zgodnie z polityką retencji.
